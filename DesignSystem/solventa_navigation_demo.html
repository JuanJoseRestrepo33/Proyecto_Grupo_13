✨ Características Clave

Desktop Navigation

  • Sidebar persistente (240px) con primarias y secundarias
  • Header con navegación horizontal (Inicio, Pólizas, Siniestros, Soporte)
  • Notifications badge (rojo con contador)
  • Profile dropdown menu
  • Active state con border-left azul
  • Hover effects suave (150ms)
  • Max 2 clics para cualquier pantalla

Mobile Navigation

  • Header compacto (56px) con hamburger menu
  • Bottom navigation (4-5 items principales)
  • Drawer sidebar en overlay modal
  • Full-width content (16px margins)
  • Touch targets min 44×44px
  • Notifications badge en header
  • Smooth animations (250ms)

Tablet Transition (768px-1023px)

  • Sidebar se convierte en hamburger
  • Header con nav items horizontales
  • Drawer overlay aparece en click
  • Contenido full-width
  • Transición suave entre layouts

♿ Accesibilidad (WCAG 2.1 AA)

Keyboard Navigation

Tab entre items, Enter para activar, Esc para cerrar

Focus Indicators

Border 2px azul (#1E40AF) siempre visible

Screen Reader

ARIA labels, semantic HTML, aria-current="page"

Color Contrast

≥ 4.5:1 ratio WCAG AA en todos los items

Touch Targets

Min 44×44px en móvil, gap ≥ 8px

Labels + Icons

Nunca solo iconos, siempre con texto

🎯 Flujos de Usuario Principales

1. Nuevo usuario cotiza (Desktop)

Home → Click "Cotizar" → Modal 4-step Wizard → Confirmación → Notificación

2. Nuevo usuario cotiza (Móvil)

Home (🏠) → Tap CTA "Cotizar" → Full-screen Wizard → Confirmación → Bottom nav actualiza

3. Usuario reporta siniestro (Desktop)

Sidebar "Siniestros" (badge: 3) → Listado → Click en siniestro → Detalle → Reportar

4. Usuario ve sus pólizas (Móvil)

Bottom nav "📋 Pólizas" → Grid cards → Tap en card → Detalle → Modificar/Renovar/Cancelar
